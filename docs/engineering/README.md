# 工程记录索引

这个目录记录项目是怎样被做出来的，不只展示最后结果。

- [`project_journal.md`](project_journal.md)：按时间记录现象、假设、实验、证据、决策和限制。
- [`decision_log.md`](decision_log.md)：把完整时间线压缩成“现象、隔离、决策、边界”的检索表。
- [`experiment_template.md`](experiment_template.md)：以后每次正式实验都按同一模板填写。
- [`interview_stories.md`](interview_stories.md)：从真实日志提炼的面试 STAR 素材，不添加日志中没有的事实。

阅读代码之前，先看工程日志；准备面试时，再用日志中的路径亲自复现实验。
