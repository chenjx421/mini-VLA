# SO-ARM100 Pick-Place Demonstrations v2

This tracked dataset contains 120 successful MuJoCo demonstrations generated by
the repository's waypoint expert. It is included so a fresh clone can audit,
train, and evaluate the Tiny-VLA without recollecting data.

## Scope

- 3 target colors: red, green, blue
- 2 goal sides: left, right
- 20 successful episodes for each color/side pair
- 18,972 valid control steps
- 64 x 64 RGB, 12D proprioception, 5D normalized actions
- domain-randomized lighting and physics
- `contact_assisted` grasp mode, explicitly not strict contact-only grasping

## Integrity

Run:

```bash
evla-audit-dataset datasets/so_arm_pick_place_v2_120_dr
```

Expected dataset fingerprint:


The generated `statistics.json` records shape checks, task balance, phase counts,
normalization statistics, and the manifest hash. Every episode is generated data
and is licensed under the repository MIT license.
